# Action schemas

This directory stores native action text, semantic definitions, and enumerated values separately.

- `gsm8k/base.yaml` and `alfworld/base.yaml` select an action name, then generate argument text.
- `alfworld/base_closed.yaml` selects an action name and enumerated values in fixed slot order.
- `webshop/base.yaml` selects only `search` or `click`, then generates the query or visible target with the original vocabulary.
- `codegym_generated/base/*.yaml` contain JSON call prefixes generated by `experiments/shared/dataset/codegym.py schema`.
- `mcp.json` (or `codegym_generated/mcp/*.json`) supplies semantic action descriptions.
- `alfworld/values.yaml` supplies enumerated value sets.

`surface_form` specifies the fixed text written after action selection.
`surface_form_suffix` supplies fixed slot separators where applicable.
Argument names are not action-head choices.

WebShop serializes the actual emitted native command rather than joining an action name and arguments with whitespace.
Its opt-in `preserve_exit_prefix` keeps characters merged with the closing marker in a tokenizer token, such as the `]` in `]</`.
Rollout and policy replay use the same router, preserving the sampled vocabulary ID for training while forcing the canonical marker text.
Incomplete commands are not repaired into executable purchases, and page-specific click targets are not a dynamic action head in this schema.

The supported experiment combinations are declared in `experiments/shared/train_eval/config/README.md`.
The generator reads upstream CodeGym action definitions and writes native JSON schemas and matching MCP definitions.

To regenerate from the retained semantic definitions without the upstream dump:

```bash
python experiments/shared/dataset/codegym.py schema --from_mcp agent_system/policies/dyad/actions/schemas/codegym_generated/mcp --outdir /tmp/codegym-native
```

This preserves the complete MCP documents, including parameter types and constraints.
